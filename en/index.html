Version control

Keeping the history of the code and working without fear of losing anything.

Version control keeps every change with its history, lets you try ideas without risk and go back when something breaks. Git does that work locally and GitHub takes it to the cloud to share it.

What I have been able to learn

  • Recording changes in a repository in an orderly way.
  • Working with branches and recovering an earlier version.
  • Pushing and syncing a project with GitHub.

Tools

  • GitRecording changes and going back when needed.
  • GitHubHosting repositories and keeping the code available in the cloud.
  • GitHub from AntigravityHandling the repository without leaving the AI editor.
$ git commit -m "avance"

  • Querying data with SELECT, JOINs and subqueries.
  • Connecting the database to Python through SQLAlchemy.

Tools

  • SQLLanguage to request and change data.
  • MySQLDatabase system that stores information in tables.

Publish online

Getting a website online and keeping it running.

A site does not exist until it is online. Cloudflare Pages publishes a static website from its GitHub repository, Wrangler lets you do it from the terminal and hosting keeps your own site online.

What I have been able to learn

  • Connecting a repository to Cloudflare Pages and publishing a static site.
  • Using Wrangler to deploy and manage projects from the terminal.
  • Hosting your own site and keeping it online and up to date.
  • Handling the basics of the Cloudflare dashboard.

Tools

  • CloudflareHandling the basics of a project and its services from the dashboard.
  • Cloudflare PagesPublishing static sites linked to a GitHub repository.
  • WranglerManaging and publishing Cloudflare projects from the command line.
  • Web hostingHaving your own site hosted, online and up to date.
