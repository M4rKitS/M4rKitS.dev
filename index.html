Entorno de trabajo

Dónde se trabaja: el sistema, la terminal y el editor.

Todo proyecto empieza en un entorno bien montado. Aquí entran el sistema Linux, la terminal con su shell y el editor donde se escribe y se revisa el código: la base sobre la que se apoya el resto del trabajo.

Lo que he podido aprender

  • Moverme por carpetas y archivos desde la línea de comandos.
  • Lanzar y encadenar comandos sin depender del ratón.
  • Dejar el editor preparado para escribir y revisar código con comodidad.

Herramientas

  • Linux y terminalMoverse por el sistema y lanzar tareas desde la línea de comandos.
  • ZshIntérprete de comandos para trabajar cómodo en la terminal.
  • VS CodeEditor donde se escribe, se prueba y se revisa el código.
$ cd mi-proyecto && code .

Control de versiones

Guardar la historia del código y trabajar sin miedo a perder nada.

El control de versiones guarda cada cambio con su historia, permite probar ideas sin riesgo y volver atrás cuando algo falla. Git hace ese trabajo en local y GitHub lo lleva a la nube para compartirlo.

Lo que he podido aprender

  • Registrar cambios en un repositorio de forma ordenada.
  • Trabajar con ramas y recuperar una versión anterior.
  • Subir y sincronizar un proyecto con GitHub.

Herramientas

  • GitRegistrar cambios y volver atrás cuando haga falta.
  • GitHubAlojar repositorios y dejar el código disponible en la nube.
  • GitHub desde AntigravityManejar el repositorio sin salir del editor con IA.
$ git commit -m "avance"

Pensar la solución y escribirla en código.

Antes de escribir una línea hay que saber qué pasos resuelven el problema. De ahí se pasa a un lenguaje, Python, a organizar el código con objetos y a dar forma a una página con HTML y CSS.

Lo que he podido aprender

  • Descomponer un problema en pasos con pseudocódigo.
  • Escribir programas en Python con condiciones, bucles y funciones.
  • Organizar el código en clases y objetos.
  • Maquetar una página con HTML y darle estilo con CSS.

Herramientas

  • Lógica y pseudocódigoPlantear los pasos de un problema antes de programarlos.
  • PythonLenguaje para escribir programas y automatizar tareas.
  • Programación orientada a objetosOrganizar el código en clases y objetos reutilizables.
  • HTMLLa estructura y el contenido de una página web.

Datos

Guardar la información, consultarla y relacionarla.

Casi toda aplicación necesita guardar información y recuperarla. Esta área recorre cómo se diseñan las tablas y sus relaciones, cómo se piden los datos con SQL y cómo se manejan desde Python con un ORM.

Lo que he podido aprender

  • Crear tablas y relacionarlas entre sí.
  • Consultar datos con SELECT, JOIN y subconsultas.
  • Conectar la base de datos con Python mediante SQLAlchemy.

Herramientas

  • SQLLenguaje para pedir y modificar datos.
  • MySQLSistema de bases de datos que guarda la información en tablas.
  • Consultas con JOIN y subconsultasCombinar tablas y filtrar con consultas anidadas.
  • Relaciones entre tablasDiseñar cómo se conectan los datos entre sí.
  • SQLAlchemy y ORMTrabajar con la base de datos desde Python usando objetos.

Publicar en internet

Sacar un sitio web a internet y mantenerlo en marcha.

Un sitio no existe hasta que está en internet. Cloudflare Pages publica una web estática desde su repositorio de GitHub, Wrangler permite hacerlo desde la terminal y el alojamiento mantiene la web propia en línea.

Lo que he podido aprender

  • Conectar un repositorio con Cloudflare Pages y publicar un sitio estático.
  • Usar Wrangler para desplegar y gestionar proyectos desde la terminal.
  • Alojar una web propia y mantenerla en línea y actualizada.
  • Manejar lo básico del panel de Cloudflare.

Herramientas

  • CloudflareManejar lo básico de un proyecto y sus servicios desde el panel.
  • Cloudflare PagesPublicar sitios estáticos enlazados a un repositorio de GitHub.
  • WranglerGestionar y publicar proyectos de Cloudflare desde la línea de comandos.
  • Alojamiento webTener una web propia alojada, en línea y al día.
$ wrangler pages deploy
